# Colmeia de Morville (2004)

Para o software e a tarefa analisados, escreva UMA frase por faceta, citando um elemento concreto da interface (não opinião genérica).

| Faceta | Pergunta-guia |
|---|---|
| Útil | O produto resolve uma necessidade real da persona? |
| Utilizável | A tarefa é concluída com facilidade e poucos passos? |
| Desejável | Visual, marca e emoção despertam vontade de usar? |
| Encontrável | O conteúdo/função é fácil de achar (navegação, busca)? |
| Acessível | Pessoas com limitações (visão, audição, motor) conseguem usar? |
| Crível | O usuário confia (feedback fiel, dados consistentes)? |
| Valioso | Entrega valor ao usuário e ao negócio? |

Ao final, proponha UMA melhoria ligada a 1–2 facetas fracas, com métrica mensurável (tempo, toques, taxa de erro).
